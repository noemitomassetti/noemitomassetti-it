2. Estratto Guida Utente: Configurazione Single Sign-On (SSO)

Passo 3: Assegnazione dei ruoli e provisioning Just-In-Time (JIT)

Una volta configurato il provider di identità (IdP) conforme allo standard SAML 2.0, abilitare l'opzione «Attiva provisioning automatico utenti». I nuovi collaboratori che accedono con il dominio aziendale verificato riceveranno automaticamente il ruolo predefinito di Membro Standard, salvo diversa regola di mappatura impostata nel pannello di sicurezza.
